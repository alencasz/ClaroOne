CLARO ONE — GUIA RÁPIDO PARA WINDOWS
=====================================

Siga os passos abaixo na ordem. Não é necessário saber programar.


PASSO 1 — INSTALAR OS PROGRAMAS
-------------------------------

Instale estes três programas:

1. Git: https://git-scm.com/download/win
2. Python: https://www.python.org/downloads/windows/
3. Ollama: https://ollama.com/download/windows

Ao instalar o Python, marque a opção para adicionar o Python ao PATH.


PASSO 2 — BAIXAR O PROJETO
--------------------------

Abra o PowerShell, copie cada comando abaixo e pressione Enter:

git clone https://github.com/alencasz/ClaroOne.git
cd ClaroOne


PASSO 3 — INSTALAR AS DEPENDÊNCIAS
----------------------------------

Ainda no PowerShell, execute um comando de cada vez:

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

A instalação pode demorar alguns minutos.


PASSO 4 — PREPARAR A IA DE CONTEXTO
-----------------------------------

Abra o aplicativo Ollama. Depois execute no PowerShell:

ollama pull qwen3:4b

Aguarde o download terminar. Isso só precisa ser feito uma vez.


PASSO 5 — INICIAR O PROJETO
---------------------------

Execute:

.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000

Não feche essa janela do PowerShell enquanto estiver usando o projeto.

Abra o navegador neste endereço:

http://127.0.0.1:8000


PASSO 6 — TESTAR A DEMONSTRAÇÃO
-------------------------------

1. Na página inicial, clique em Telefone / URA.
2. Digite o CPF fictício 123.456.789-00.
3. Escolha um setor.
4. Carregue um arquivo da pasta Audios:

   - RogerFatura.mp3: escolha Fatura e pagamentos.
   - BellaInternet.mp3: escolha Internet.
   - SarahCancelar.mp3: escolha Cancelamento.

5. Clique em Encerrar ligação.
6. Aguarde a transcrição e a análise do contexto.
7. Continue pelo WhatsApp ou Minha Claro.
8. Abra o Cockpit para ver o contexto completo.

Na primeira utilização, o Whisper baixará o modelo de transcrição. Esse primeiro
processamento precisa de internet e pode demorar mais que os próximos.


PARA INICIAR NOVAMENTE EM OUTRO DIA
-----------------------------------

1. Abra o aplicativo Ollama.
2. Abra o PowerShell.
3. Entre na pasta onde o projeto foi baixado:

cd ClaroOne

4. Inicie o projeto:

.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000

5. Abra http://127.0.0.1:8000


TESTE AUTOMATIZADO OPCIONAL
---------------------------

Para verificar o projeto, execute dentro da pasta ClaroOne:

.\.venv\Scripts\python.exe -m pytest -q


INFORMAÇÕES ÚTEIS
-----------------

- Para parar o projeto, pressione Ctrl+C no PowerShell.
- Para limpar os atendimentos, use Reiniciar demonstração na página inicial.
- Todos os nomes e CPFs do sistema são fictícios.
- O projeto não precisa de chave de API.
